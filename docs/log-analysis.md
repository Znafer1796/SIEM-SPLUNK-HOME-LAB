## Use Case: Firewall Log Analysis During Nmap Scanning

### Objective
Investigate firewall events generated during a controlled Nmap scan from Kali Linux and examine the corresponding logs collected by Splunk Enterprise.

### Investigation
1. Query `index="main"` to review the collected events.
2. Query `index="main" filterlog "block"` to narrow the results to events containing the `block` keyword.
3. Compare the search results with the Nmap test timeline and OPNsense Firewall Live View.
4. Correlate the source IP, destination IP, protocol, destination port, action, and timestamp.

### Observations
The baseline search returned 8,399 events, while the search containing the `block` keyword returned 5,427 events for the displayed time ranges.

The filtered results contain OPNsense `filterlog` events with the `block` action. These results demonstrate that firewall block events are being collected and can be investigated in Splunk.

The event counts alone do not establish that all filtered events were generated by Nmap. Further correlation with the scan time and network addresses is required.
